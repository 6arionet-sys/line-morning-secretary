# 毎朝LINEに届く「朝の秘書」通知システム

毎朝 5:30（日本時間）に、いつも使っているLINEへ「天気・ゴミの日・今日の予定・釣り予報」がまとまった見やすいカード（Flex Message）が1通届く自動化システムです。

PCの電源を消していても、GitHub Actionsが完全無料で毎朝自動実行します。

---

## 届くメッセージのイメージ

- **ヘッダー**：朝焼けのグラデーション、今日の日付・曜日、天気の概要
- **今日の天気**：横浜の最高/最低気温、傘の要否、6〜24時のタイムラインバー、洗濯指数、AIによる服装アドバイス
- **ゴミの日**：今日のゴミ出し（月・木: 燃えるゴミ / 水: 瓶・缶・ペットボトル / 土: 資源ごみ）
- **今日の予定**：Googleカレンダーから「今日・明日・この先1週間」の予定を自動抽出
- **釣り予報**：城ヶ島の波の高さ・風向き・風速、Geminiによる「今日の釣り日和（星1〜5つ）」とワンポイントアドバイス
- **フッター**：気象庁予報ページへのリンク

## 完全無料でのセットアップ手順（約10分）

### STEP 1. Gemini APIキーの取得（所要時間：1分）
天気の数値から「服装のアドバイス」や「釣り日和」を判定するために使用します（完全無料）。

1. [Google AI Studio](https://aistudio.google.com/) にアクセスします。
2. お手持ちの Google アカウントでログインします。
3. 左上または画面中央の **「Get API key」** ボタンを押し、**「Create API key」** をクリックします。
4. 表示された英数字のキーをコピーしてメモ帳などに控えます。

---

### STEP 2. LINE公式アカウントの作成＆トークン取得（所要時間：5分）
自分宛てにLINEメッセージを送信するための公式アカウントを作ります（完全無料）。

1. **公式アカウントの開設**
   - [LINE Official Account Manager](https://manager.line.biz/) にアクセスします。
   - **「LINEアカウントでログイン」** をクリックし、普段スマホでお使いのLINEアカウントでログインします。
   - 「アカウント名」（例：`朝の秘書`）を入力し、大業種・小業種を適当に選択（例：個人など）して作成を完了します。
2. **Messaging API の有効化**
   - アカウント管理画面の右上にある **「設定」**（歯車マーク）をクリックします。
   - 左側メニューの **「Messaging API」** を選択します。
   - **「Messaging APIを利用する」** ボタンをクリックします。
   - 開発者名（ニックネームなど）とメールアドレスを入力して同意・登録します。
3. **アクセストークンとユーザーIDの取得**
   - 登録完了画面にある「LINE Developers」のリンクをクリックして開きます（または [LINE Developers コンソール](https://developers.line.biz/console/) を開きます）。
   - 作成したチャネルを開き、**「Messaging API設定」** タブを開きます。
   - ページ一番下にある「チャネルアクセストークン」の **「発行」** ボタンを押し、表示された長い文字列をコピーして控えます。
   - **「チャネル基本設定」** タブに戻り、ページ下部にある **「あなたのユーザーID」**（`U` から始まる33文字程度の文字列）をコピーして控えます。
4. **公式アカウントを友だち追加**
   - 管理画面のQRコードをスマホのLINEカメラで読み取り、作成した公式アカウントを**友だち追加**しておきます。

---

### STEP 3. Googleカレンダーの非公開URLを取得（所要時間：1分）

1. PCのブラウザで [Googleカレンダー](https://calendar.google.com/) を開きます。
2. 画面左側の「マイカレンダー」一覧にある、連携したいカレンダー（通常は自分の名前のカレンダー）にカーソルを合わせ、右側の **「︙（3点リーダー）」** → **「設定と共有」** をクリックします。
3. 画面を下にスクロールし、**「カレンダーの統合」** セクションを探します。
4. **「iCal 形式の非公開 URL」** の枠内にあるURLをコピーして控えます。
   - ※「一般公開のURL」ではなく、必ず「非公開URL」をコピーしてください。

---

### STEP 4. GitHubリポジトリの作成とSecretsの設定（所要時間：3分）

1. [GitHub](https://github.com/) にログインし、新しいリポジトリ（Public）を作成します（例: `line-morning-secretary`）。
2. 本フォルダ内のファイルをリポジトリへアップロード（または git push）します。
3. リポジトリのページ上部にある **「Settings」** タブをクリックします。
4. 左側メニューの **「Secrets and variables」** → **「Actions」** を選択します。
5. **「New repository secret」** ボタンを押し、以下の4つを1つずつ登録します：

| Name（名前） | Secret（値） |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | STEP 2で発行した「チャネルアクセストークン」 |
| `LINE_USER_ID` | STEP 2で控えた「あなたのユーザーID」 |
| `GEMINI_API_KEY` | STEP 1で取得した「Gemini APIキー」 |
| `GOOGLE_CALENDAR_ICS_URL` | STEP 3で取得した「GoogleカレンダーのiCal非公開URL」 |

---

### STEP 5. 動作テスト（今すぐ手動で送ってみる）

1. リポジトリ上部の **「Actions」** タブをクリックします。
2. 左メニューにある **「Morning Secretary Bot」** ワークフローを選択します。
3. 右側にある **「Run workflow」** ドロップダウンをクリックし、緑色の **「Run workflow」** ボタンを押します。
4. 数十秒待つと実行が完了し、あなたのスマホのLINEに朝の秘書カードが届きます！

---

## 毎朝の自動実行について

- 日本時間で **毎朝 5:30**（気象庁の朝5時発表データ更新後）に自動で起動し、LINEに通知が届きます。
- GitHub Actions の仕様（60日間アクセスのないリポジトリのcron自動停止）に対応するため、実行のたびに自動で安全な keep-alive コミット（`last_run.txt` の更新）を行う仕組みが組み込まれており、メンテナンスフリーで運用できます。

  "fishing_spots": [
    { "name": "城ヶ島", "area_code": "140000", "sub_area": "東部" }
  ],
  "weekly_schedule": {
